# Cote Réelle — package complet

- `estimation-vehicule.html` : le site, à ouvrir directement dans un
  navigateur (double-clic) ou à héberger. Fonctionne seul, sans rien
  d'autre.
- `backend/` : optionnel, PHP+MySQL, pour un historique persistant
  multi-appareils avec comptes utilisateurs. Voir `backend/README.md`.
- `extension/` : optionnelle, extension navigateur pour extraire
  automatiquement une annonce depuis la page ouverte. Voir
  `extension/README.md`.

Commence par `estimation-vehicule.html` seul — les deux autres
dossiers sont des évolutions à brancher quand tu en as besoin.
