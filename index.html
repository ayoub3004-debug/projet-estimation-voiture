Tant que rien n'est connecté, les chiffres sont simulés : ils viennent d'un modèle de décote interne, pas d'annonces réelles. Un bandeau le rappelle sur chaque estimation.

Le service appelé reçoit la fiche du véhicule en JSON et doit répondre :
{ valeurExcellent, valeurMoyen, valeurMediane, nbTotal, source, annonces:[{titre,prix,km,annee,departement,source,lien}] }
Les fichiers api/cote.php et api/cote.js fournis avec le site servent d'adaptateur : la clé du fournisseur y reste côté serveur, jamais dans le navigateur.
